# 인수인계: 여기서 시작하세요

이 자료는 Philips Evnia의 후원으로 개관한 한국외국어대학교 Esports Lab 예약 홈페이지를 다음 담당자가 이어서 관리하기 위한 안내입니다. **로컬 구현 완료, GitHub 공유, 운영 사이트 배포는 서로 다른 상태**이므로 먼저 진행표를 확인하세요.

## 처음 맡은 날 읽는 순서

1. [프로젝트 README](../README.md): 서비스 목적, 현재 기능, 로컬 실행 방법을 읽습니다.
2. [현재 진행표](07-progress.md): 완료한 수정, 실제 검증 결과, 다음 작업, 배포 여부를 확인합니다.
3. [개발·인수인계 가이드](04-maintainer-guide.md): 코드 위치를 찾고 가상 데이터로 실행·검증합니다.
4. [Git 작업·커밋 규칙](08-git-workflow.md): 작업 브랜치를 만들고 목적 단위로 검증 후 커밋합니다.
5. [배포·복구 가이드](05-deployment.md): PythonAnywhere의 실제 설정과 DB를 확인한 뒤 배포 순서를 따릅니다.

기술 선택과 구현 방식의 적합성은 [기술 선택·검토 기록](09-technical-decisions.md)을 함께 읽으세요. 초기 문제의 근거는 [현황 진단](01-audit.md), 목표 기능은 [기능·데이터 설계](02-product-spec.md), 오픈 준비는 [개관 체크리스트](06-launch-plan.md)에 있습니다. 초기 진단은 수정 전 상태를 기록한 자료이므로 지금 상태는 진행표와 테스트 결과를 기준으로 판단합니다.

## 작업을 이어가는 순서

**진행표 확인 → Git 상태 확인 → 작은 작업 선택 → 구현·검증 → 관련 문서 갱신 → 목적별 커밋 → 인수인계 묶음 갱신** 순서로 진행합니다. 운영 반영은 그 뒤 별도 배포 절차로 진행합니다.

중단하기 전에 진행표에 현재 브랜치, 완료한 일, 마지막 검증, 남은 일과 재개 명령을 적습니다. 미완성 작업을 완료 처리하지 말고 운영 DB·계정 정보·환경변수 값은 문서나 Git에 넣지 않습니다. 접근 권한 인계는 운영 책임자에게 별도로 받습니다.

## 이 묶음을 읽는 방법

ZIP을 받은 경우 폴더에 **압축을 먼저 풀고 `index.html`을 브라우저에서 여세요.** 문서별 화면, 전체 내용을 한 번에 읽는 `guide.html`, Markdown 원문이 함께 있습니다. 안내 페이지는 인터넷 없이 읽을 수 있고, 공식 문서·GitHub·운영 사이트 링크는 인터넷 연결이 필요합니다.

`manifest.json`에는 기준 커밋, 브랜치, 커밋하지 않은 변경 여부, 최근 커밋, 문서별 SHA-256과 파일 크기가 들어 있습니다. `working_tree_dirty`가 `true`이면 커밋 이후의 문서 변경까지 포함한 검토용 묶음입니다. 이 파일의 버전 정보가 운영 서버 버전과 같다는 뜻은 아닙니다.

## 새 인수인계 묶음 만들기

저장소 루트에서 개발 의존성을 설치한 뒤 실행합니다. 최종 공유본은 문서와 코드 검증을 끝내고 커밋한 다음 생성합니다.

```powershell
python -m pip install -r requirements-dev.txt
python tools/build_handover.py --require-clean
```

검토용으로 현재 수정 중인 문서를 묶으려면 `--require-clean`을 생략할 수 있습니다. 결과는 Git에서 제외하는 `artifacts/hufs-esports-handover-<커밋>-<내용해시>.zip`에 생성됩니다. 도구는 문서 허용 목록, HTML 내부 링크·앵커, ZIP 무결성을 검사합니다. 같은 문서 내용·Git 상태·도구·Markdown 버전·Python 실행환경으로 생성하면 동일한 ZIP이 나옵니다.

포함 대상은 README, AGENTS, CHANGELOG(있는 경우), `docs/*.md`, `docs/audit/*.json`과 생성된 HTML·버전 기록뿐입니다. 실행 코드·DB·학생 정보·비밀 설정·백업은 포함하지 않습니다. **코드를 수정할 때는 ZIP을 실행 폴더로 쓰지 말고 GitHub 저장소를 복제하세요.**
