## 동작하는 부분과 추가 정리

- 순차 요청에서는 같은 좌석의 겹치는 예약과 학생의 두 번째 당일 예약을 차단했습니다. 동시성 안전성까지 입증한 것은 아닙니다.
- 화면 도면은 **1–27번**을 만들지만 `models.py` 주석은 **1–28번**입니다. 실제 시설에서 확정해야 합니다.
- 학생 화면은 **09–17시**, 모델·관리 차단 입력에는 **18시**도 등장합니다. 최대 이용 시간 문구는 3시간 고정인데 관리 설정은 변경할 수 있습니다.
- 예약일 선택은 브라우저에서 오늘부터 +7일까지이므로 양끝을 포함하면 8개 날짜입니다. 관리자 차트는 오늘부터 7개 날짜입니다.
- 취소 예약은 관리자 조회에서 제외되어, 과거 기록 화면의 ‘취소됨’ 표시 분기에 도달하지 않습니다. 취소 이력 조회가 필요합니다.
- 학생 삭제 후 예약은 남습니다. 같은 학번으로 재가입하거나 학번을 수정할 때 이력 소유권 정책이 필요합니다.
- 서버는 `datetime.now()`의 로컬 시간, 프런트는 방문자 기기 시간, 생성 시각은 UTC를 사용합니다. `Asia/Seoul` 기준을 명시해야 합니다.
- 영구 정지는 약 100년 뒤로 저장하지만 표시 조건은 연도 2900 초과라서 표시가 맞지 않습니다.
- `auth_helpers.py`는 필요한 객체 import가 없어 직접 import하면 실패하며 현재 `app.py`는 이 파일을 사용하지 않습니다.
- `test_logic.py`는 고정 날짜·기존 계정·별도 실행 서버에 의존하고 결과를 출력할 뿐 assert가 없습니다. 필요한 `requests`도 requirements에 없습니다.
- `convert.py`는 이전 PC의 `C:/EsportsLab/...` 경로를 사용합니다. 일반 실행에 필요하지 않은 로고 변환 보조 스크립트입니다.
- README, 마이그레이션, CI, 배포 설정, 환경변수 예시, 백업 절차가 원본 저장소에 없었습니다. `.gitignore`에는 `.env` 제외도 없습니다.

## 화면에서 확인한 불편

첫 방문 시 실습실 소개·위치·이용 방법 없이 로그인 폼만 보입니다. 한국어 화면에 로그인 필요 안내가 영어로 나옵니다. 390px 회원가입 화면에서는 큰 브랜드 제목과 세로 메뉴가 상단 상당 부분을 차지하며 가입 완료 버튼이 첫 화면 밖에 있습니다.

예약 화면은 소스 기준으로 학생 이름·학번, 시간 입력, 도면만 제공합니다. 좌석은 클릭 가능한 `div`로 구현되어 키보드 선택이 어렵습니다. 가용성 통신 실패는 콘솔에만 출력되고, 여러 조회 응답이 순서가 바뀌어 도착하는 상황에 대한 방어가 없습니다. 디자인 기준은 [별도 문서](03-design-guide.md)에 제안했습니다.

## 배포·이전 작업에서 아직 모르는 것

PythonAnywhere의 계정 관리 권한, Web 탭의 소스·가상환경·WSGI 경로, 서버 Python 버전, 실제 배포 커밋, 서버에서만 수정한 파일, DB 스키마·백업, 도메인·예약 작업·외부 연동을 확인해야 합니다. GitHub만으로 과거 Antigravity 대화나 미커밋 작업을 복원할 수는 없습니다. 서버 파일과 로컬의 옛 작업 폴더를 비교하면 누락분을 찾을 수 있습니다.

Flask의 기본 CSRF·쿠키 고려사항은 [공식 보안 문서](https://flask.palletsprojects.com/en/stable/web-security/)를 참고했습니다. 이는 개선 설계의 근거이며 현재 코드에 해당 보호가 적용되었다는 뜻이 아닙니다.
