# 월간 일정표와 메인 운영 상태

2026-10-10 로컬 구현·검수 완료. 현재 작업은 아직 커밋·푸시·운영 배포하지 않았습니다. 이전 구상에서 개별 좌석 점검 표시는 제외하는 사용자 결정을 반영했습니다.

## 공개 화면

메인 사진 아래(모바일에서는 예약·소개 버튼 다음)에 색 점·상태명·오늘 개방 시간·월간 일정 링크를 배치합니다. 한국 시간 기준으로 `운영 중`, `개방 전`, `수업·대관 중`, `오늘 운영 종료`, `오늘 휴실`을 판단하고 현재 수업·대관·행사·휴무명을 상태명 옆에 표시합니다. 별도 사유 줄은 제거하고 확인 시각은 월·일·시간 기준으로 표시합니다. 신규 예약 접수 중지는 운영 상태와 별도로 표시합니다. 운영 중이나 달력의 개방 표시는 잔여 좌석을 보장하지 않습니다.

이용 방법 아래 `이달의 일정`은 일요일부터 시작하는 7열 달력입니다. 오늘을 기본 선택하고 이전/다음 월·오늘 이동을 제공합니다. 날짜 칸은 휴실이나 일정이 있을 때만 보조 표시하고 일정이 없는 날의 빈 목록 안내는 숨깁니다. 상세 시간 앞에는 운영시간을 붙입니다. 날짜를 선택하면 PC는 옆, 모바일은 아래에 실제 개방 시간과 수업·대관·행사 제목 및 시간을 표시합니다. 예를 들어 14:00–16:00 전체 대관이면 개방 시간은 `09:00–14:00 / 16:00–17:00`입니다. 겹친 차단은 합집합으로 계산합니다.

초기 화면은 서버에서 렌더링합니다. 열린 화면은 1분마다, 다시 활성화할 때 공개 API로 상태와 달력을 갱신합니다. 갱신 실패 시 상태는 `운영 상태 확인 필요`로 바뀌고 마지막 조회 결과임을 표시합니다. JavaScript가 없어도 월 이동과 날짜별 안내를 읽을 수 있습니다.

## 자동 반영과 예약 규칙

| 기준 | 공개 달력·상태 및 실제 예약 |
| --- | --- |
| 기존 운영 시작·종료 시각 | 날짜별 기본 개방 시간 |
| 운영 요일 설정 | 기본 월–금, 관리자가 변경 가능; 선택하지 않은 요일은 휴실 |
| 한국 공휴일·대체공휴일 | `holidays` 한국 달력의 등록된 휴일은 자동 휴실 |
| 기존 `RecurringBlock` | 정기 수업으로 표시하고 전체 예약 차단 |
| 기존 전체 좌석 `BlockedTime` | 대관·행사로 표시하고 전체 예약 차단 |
| 개별 좌석 `BlockedTime` | 공개 달력·운영 상태에서 제외; 해당 좌석의 예약 차단은 유지 |
| 새 `CalendarEvent` | 공개 제목·기간·요일·시간과 유형에 따라 안내 또는 전체 예약 차단 |

`lab_schedule.py`의 같은 계산을 공개 달력·운영 상태·예약 가용성·최종 예약·관리자 좌석도에서 이용합니다. 공휴일이나 비운영 요일에는 새 예약을 받지 않습니다. 설정 변경으로 기존 예약을 자동 삭제·취소하지 않지만, 현장 방문 확인에도 차단 검사가 적용되므로 운영 요일 변경 전에 기존 예약을 확인하고 운영진이 안내해야 합니다.

학생 예약·이름·학번·IP 및 기존 내부 차단 사유는 공개 API에 포함하지 않습니다. 기존 차단은 `정기 수업`·`대관·행사`라는 일반 제목으로 공개하고 새 일정에는 관리자가 입력한 공개 제목을 사용합니다.

## 관리자 일정 관리

달력 공개 기간은 `calendar_future_months` 설정에 저장합니다. 기본 3개월, 0~12개월 뒤까지 조절하며 이번 달은 항상 공개합니다. 매월 기준이 이동하고 과거 조회는 유지합니다. 공개 홈과 API는 같은 범위를 검사하므로 주소로 미공개 일정을 조회해도 404입니다. 열린 화면에서 공개 범위가 축소되면 이번 달로 돌아갑니다. 관리자는 미공개 기간의 일정을 미리 등록할 수 있으며 학생의 예약 가능 일수에는 영향을 주지 않습니다. 이 후속 설정은 기존 setting 테이블을 사용하고 별도 migration은 없습니다.

예약 관리 상단의 `실습실 일정 관리`(`/admin/calendar`)에서 다음을 설정합니다.

- 운영 요일 및 기존 예약 관리의 개방 시각.
- 수업·단체 대관·행사·휴실: 시작/종료 날짜, 기간 내 모든 날짜 또는 매주 지정 요일, 종일 또는 30분 단위 시작/종료 시간. 기간은 시작일 포함 최대 366일입니다.
- 수업·대관·휴실은 해당 시간 전체 예약을 차단합니다. 행사는 안내만 하거나 전체 예약도 차단할 수 있습니다.
- 기존 활성 예약과 겹치는 새 차단·수정·재게시 요청은 오류로 막고 예약을 보존합니다.
- 등록 목록에서 수정·중지·다시 게시합니다. 중지는 공개 표시와 그 일정의 차단을 함께 해제하며 기록을 삭제하지 않습니다.

기존 반복 수업은 적용 기간이 없으므로 원래 동작을 유지합니다. 학기별 수업에는 새 일정 관리에서 날짜 범위와 반복 요일을 지정하세요. 같은 수업을 두 곳에 중복 등록하지 않습니다. 기존 차단의 수정·해제는 기존 예약 관리에서 합니다.

새로 지정되는 임시 공휴일·학교 휴무일은 관리자에서 `휴실`로 등록합니다. 공휴일 라이브러리는 고정 버전이므로 향후 정부의 새 지정이 항상 즉시 반영되는 것은 아닙니다. 의존성 업데이트 때 공식 휴일 발표와 한국 달력을 확인하고 테스트하세요.

## 데이터·배포와 확인

`0011_public_lab_calendar`은 새 일정 테이블과 인덱스를 만들고 운영 요일 설정이 없을 때만 월–금을 추가합니다. 기존 회원·예약·차단·게시글·팝업 및 기존 설정은 보존합니다. `requirements.txt`의 `holidays==0.106` 설치와 버전별 DB 업그레이드가 필요합니다. 운영 DB에는 `create_all`을 사용하지 않습니다. 실제 운영 revision을 먼저 확인하고 DB·업로드 파일·설정을 백업한 뒤 [배포 가이드](05-deployment.md)의 절차를 따릅니다.

로컬 미리보기 DB는 SQLite 백업 API로 백업 후 `0010`→`0011` 적용했고 학생 1·예약 5·게시글 5·팝업 2건 보존, 외래 키 검사와 DB 무결성 `ok`를 확인했습니다. 전체 회귀 테스트 110개 통과 후 관리자 좌석도 연동 검사를 추가했고 관련 테스트 22개가 통과했습니다. 휴일·대체공휴일·윤년·연말·겹친 시간·권한·CSRF·기존 예약 충돌·공개 정보 제외를 검사합니다. 가상 일정으로 관리자 등록 후 공개 달력과 개방 시간이 자동 변경되는 것을 확인했고 모바일 320/390px·태블릿 768px·PC 1440px 화면을 검수했습니다.

운영시간과 월간 일정의 정보 구조는 [롯데워터파크 공식 사이트](https://waterpark.lotteworld.com/)를 참고했습니다. 한국 휴일 계산은 [holidays의 South Korea 공식 문서](https://holidays.readthedocs.io/en/latest/auto_gen_docs/south_korea/)를 기준으로 사용합니다. 색상·배치는 이 사이트에 맞춘 자체 디자인입니다.

후속 달력의 월 이동·휴실 강조 방식은 [국립중앙도서관 도서관일정](https://www.nl.go.kr/NL/contents/N41200000000.do)을 참고해 기존 네이비·청록색에 맞게 구현했습니다.
