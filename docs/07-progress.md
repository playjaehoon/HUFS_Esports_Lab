| 단계 | 상태 | 결과·남은 일 |
| --- | --- | --- |
| 저장소·공개 화면 진단 | 완료 | 초기 기준 e0681a0, 가상 데이터 16개 동작 기록 |
| 인수인계 가이드 초안 | 완료 | 구조·기능·디자인·운영·배포·개관 문서 |
| 서버 내부 설정 확인 | 대기 | PythonAnywhere 관리페이지 로그인 필요 |
| 권한·인증·예약 문제 수정 | 진행 중 | 로컬 수정 및 회귀 테스트 예정 |
| 내 예약·정보 수정·승인 제거 | 예정 | 기존 회원·예약 이관과 함께 검증 |

커밋 기준은 [Git 규칙](08-git-workflow.md)을 따릅니다. 실제 이력은 `git log --oneline`으로 확인합니다.
