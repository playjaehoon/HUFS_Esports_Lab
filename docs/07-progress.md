- 학생은 승인 없이 가입하고 바로 예약할 수 있습니다. 가입만으로 외대 재학이 확인되는 것은 아니므로 매 방문 시 운영진이 학생증을 대조합니다.

- 이관 학생이 `나중에 하기`를 누르면 현재 로그인 세션에서만 안내를 숨기고 다음 로그인 때 다시 표시합니다. 숫자 6자리로 변경하면 안내가 종료됩니다.
- 로그인·가입 직후 좌석 예약 화면을 먼저 열며, 내 예약은 상단 메뉴에서 목록·상세로 볼 수 있고 시작 전 또는 예약 생성 후 5분 이내 예약을 직접 취소할 수 있습니다.
- 학번·이름 변경 후에도 내부 회원 ID가 유지되어 이력·제한이 보존됩니다. 과거 학번은 다른 계정의 재가입에 쓸 수 없습니다.
- 기본값은 27석, 09~17시, 최대 3시간, 7일 이내, 하루 1회입니다. 실제 좌석 수·운영 정책은 개관 전에 확인합니다.
- 운영진 방문 확인은 예약 당일 시작 10분 전부터 종료 전, 학생증 확인 후 가능합니다. 미방문(No-show)은 예약 시작 시각부터 운영진이 사유를 적어 처리합니다. 처리하면 해당 좌석은 다시 예약 가능하지만 당일 1회 이용 기록은 유지하고 7일간 정지합니다. 제한 기간의 미입실 예약도 취소·점유 해제합니다. 페이지 조회나 미체크인만으로 자동 정지하지 않습니다.
- 관리자는 글스산 전용 PC와 지정 학과 선예약 일수를 설정합니다. 기본적으로 전용 좌석·선예약 학과는 없습니다. 일반 예약 기간은 7일입니다. 임시 회원도 입력한 학과로 혜택을 받으므로 현장 학생증 대조가 필요합니다.
- 가입 직후는 임시 회원입니다. 첫 방문 확인 후 확인 회원이 되고, 학번·이름·학과 수정이나 유일한 방문 확인 취소 시 다시 임시 회원이 됩니다. 확인 회원도 매 방문 학생증을 확인합니다.
