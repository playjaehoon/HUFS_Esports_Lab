- `60 passed`와 1440px 데스크톱, 768px 태블릿, 390px·320px 모바일 시안·햄버거·게시판 목록을 확인했습니다. 초기 로컬 DB(`0002`)는 그대로 두고 별도 미리보기 DB를 `0006`으로 업그레이드해 `integrity_check=ok`, 초기 갤러리 4건·공지 1건을 확인했습니다. 메뉴의 예약하기를 누르면 비로그인 사용자는 로그인 화면으로 이동합니다.

## 이번 로컬 구현의 이용 기준

- 학생은 승인 없이 가입하고 바로 예약할 수 있습니다. 가입만으로 외대 재학이 확인되는 것은 아니므로 매 방문 시 운영진이 학생증을 대조합니다.
- 학생 비밀번호는 숫자 6자리입니다. 이관 학생은 기존 비밀번호로 로그인한 뒤 변경 안내를 건너뛰거나 새 숫자 6자리로 바꿀 수 있습니다. 운영자 비밀번호는 별도로 12~128자를 사용합니다.
- 이관 학생이 `나중에 하기`를 누르면 현재 로그인 세션에서만 안내를 숨기고 다음 로그인 때 다시 표시합니다. 숫자 6자리로 변경하면 안내가 종료됩니다.
- 로그인·가입 직후 좌석 예약 화면을 먼저 열며, 내 예약은 상단 메뉴에서 목록·상세로 볼 수 있고 시작 전 또는 예약 생성 후 5분 이내 예약을 직접 취소할 수 있습니다.
- 학번·이름 변경 후에도 내부 회원 ID가 유지되어 이력·제한이 보존됩니다. 과거 학번은 다른 계정의 재가입에 쓸 수 없습니다.
- 기본값은 27석, 09~17시, 최대 3시간, 7일 이내, 하루 1회입니다. 실제 좌석 수·운영 정책은 개관 전에 확인합니다.
- 운영진 체크인은 예약 당일 시작 이후·종료 전, 학생증 확인 후 가능합니다. 종료·노쇼는 운영진이 명시적으로 기록합니다. 페이지 조회나 미체크인만으로 자동 정지하지 않습니다.
