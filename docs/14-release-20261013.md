## 변경 목적과 결과

### 오늘 운영상태

- 운영일의 개방 전은 **운영 전**, 개방 중은 **개방**, 마지막 개방 종료 후는 **운영 종료**로 표시합니다. 공휴일·비운영 요일·종일 차단일은 **휴관**으로 유지합니다.
- 수업·대관 사이의 일시 이용 제한은 **수업 중·대관 중·수업·대관 중**으로 구분하고 다른 사유는 **일시 휴관**으로 표시합니다. 실제 개방 구간과 한국 시간을 기준으로 첫 화면·자동 갱신에 같은 결과를 제공합니다.
- 준비·일시 제한은 연한 베이지와 색 점, 개방은 청록색, 종료·휴관은 회색 계열로 구분합니다. 운영상태 표시만 바꾸며 좌석 예약 가능 기간·확정 규칙은 유지합니다.

### 회원 전화번호

- **신규 가입과 다음 회원정보 저장 시 전화번호를 필수 입력**으로 받습니다. 기존 회원은 번호가 없어도 로그인·예약을 계속할 수 있습니다.
- 국내 번호의 공백·하이픈을 정리하고 해외 번호는 +국가번호 형식을 지원합니다. 서버에서 빈 값·잘못된 문자·길이를 검증하고 모바일 입력에 전화 키보드를 사용합니다.
- 본인의 **내 정보**와 **관리자 학생 목록**에서 확인하고 관리자는 번호를 눌러 전화 앱으로 연결할 수 있습니다. 공개 화면/API·운영 기록·Excel에는 전화번호를 추가하지 않습니다.
- 전화번호만 수정하면 학생증 확인 상태를 유지합니다. 현재 비밀번호 확인과 회원 소유권 검사를 유지하며 전화번호 인증·SMS 발송·전화번호 기반 자동 계정 복구는 포함하지 않습니다.

### 여러 날 일정과 반응형 달력

- 여러 날 이어지는 공개 일정은 날짜마다 제목을 반복하는 대신 **주별로 이어지는 색 띠**에 제목을 표시합니다. 주·월 경계에서는 제목을 다시 표시하며 PC는 넓은 띠, 모바일은 높이·글자·여백을 줄인 띠를 사용합니다.
- 단일 날짜·반복 요일 일정은 날짜 칸에 표시합니다. 최대 두 겹의 띠를 배치하고 초과 일정은 **+건수**, 날짜 클릭 후 상세 목록에서 확인합니다. 긴 제목은 생략하되 상세·도움말·접근성 이름은 전체 제목을 유지합니다.
- 같은 제목의 별개 일정은 합치지 않고 대표 휴관으로 숨겨진 날짜를 가로질러 연결하지 않습니다. 날짜별 원본 일정과 예약 차단 계산, 기존 휴관 우선 표시는 유지합니다.
- 날짜 원은 크기·축소 방지·중앙 정렬·숫자 줄 높이를 고정했습니다. 월 이동은 글자 화살표 대신 **대칭 SVG 아이콘**을 원 중앙에 배치합니다.
- 자체 제공 Pretendard 600/700 글꼴을 홈에서 미리 불러오고 대체 글꼴을 보강했습니다. 외부 에디터·달력 라이브러리나 CDN 의존성을 추가하지 않습니다.
